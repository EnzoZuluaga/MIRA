# MIRA

## Monitoring Intelligence for Risk Anticipation

MIRA es un proyecto de investigación y desarrollo tecnológico orientado a crear un sistema inteligente de monitoreo ambiental y anticipación de riesgos.

El objetivo del proyecto es aprender, construir y documentar durante tres años una plataforma que combine sensores, datos satelitales, programación e inteligencia artificial para detectar o anticipar riesgos ambientales como inundaciones, sequías o incendios.

## Objetivos iniciales

- Aprender programación con Python
- Construir una infraestructura técnica profesional
- Desarrollar una metodología de documentación científica
- Integrar sensores y datos satelitales
- Crear modelos básicos de análisis y predicción ambiental
